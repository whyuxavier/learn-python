Кілька print підряд; число хвилин рахує сам Python (7 * 45), а не учень.

Завдання. Перша програма студії. Напиши програму-привітання: студія вітає нового розробника (тебе) і рахує, скільки хвилин триває твій навчальний день.

Вітаємо в ІТ-студії!
Новий розробник: Оля Коваль, 8-А клас
Уроків сьогодні: 7
Хвилин навчання: 315

Вимоги «Перевір себе»
  • Програма виводить привітання студії.
  • Виведено твоє ім'я та клас (у тексті є слово «клас»).
  • Виведено щонайменше 4 рядки.
  • Кількість хвилин Python обчислює сам: у print є множення, наприклад 7 * 45.

1Виведення даних: print і коментарі

Рамка — повторення рядка ("*" * 28), дата — через sep, решта — звичайні print.

Завдання. Анонс для екрана в холі. Виведи анонс шкільної події в рамці: назва, дата, час і місце.

****************************
   ШКІЛЬНИЙ ТУРНІР З ШАХІВ
****************************
Дата: 21.11.2026
Початок о 14:30
Місце: актова зала
****************************
Чекаємо всіх охочих!

Розв'язок

main.py
# Анонс шахового турніру
print("*" * 28)
print("   ШКІЛЬНИЙ ТУРНІР З ШАХІВ")
print("*" * 28)
print("Дата:", end=" ")
print(21, 11, 2026, sep=".")
print("Початок о 14:30")
print("Місце: актова зала")
print("*" * 28)
print("|" + " Чекаємо всіх охочих!     " + "|")

Як пояснити учням

  1. Лінія рамки: print("*" * 28) — рядок множиться на число.
  2. Назва події між двома лініями.
  3. Дата: print("Дата:", end=" ") і далі print(21, 11, 2026, sep="."). Або в одному print з sep — але тоді крапка стане й після «Дата:».
  4. Коментар із # — що робить програма.
  5. Бонус: бокова рамка — "|" + текст + "|".

Де застрягають

  • Кома між рядком і * 28 — синтаксична помилка.
  • Не розуміють end: показати, що наступний print продовжує той самий рядок.
Вимоги «Перевір себе»
  • Рамка зверху й знизу — повторенням рядка ("*" * 28).
  • Виведено назву, дату, час і місце події (щонайменше 6 рядків print).
  • Дату виведено з sep (наприклад sep=".") або рядок продовжено через end.
  • Програма має коментар з поясненням.
  • Бонус: рамка з боків — рядок на кшталт "|" + … + "|".

П'ять помилок різних типів; виправляти по одній і щоразу запускати.

Завдання. Полагодь розклад дзвінків. У програмі колеги 5 помилок. Виправ їх так, щоб програма вивела розклад, як у прикладі.

2 урок: 09:25–10:10
3 урок: 10:30–11:15

Розв'язок

Де застрягають

  • Помилка з дужкою показується на рядку нижче — пояснити, що Python «помічає» її пізніше.
  • Хочуть виправити все одразу — радити по одній помилці.
Вимоги «Перевір себе»
  • Закрито лапки в заголовку.
  • Виправлено описку в назві команди.
  • Прибрано зайвий відступ.
  • Додано пропущену дужку.
  • Останній рядок виводить текст і числа без TypeError, а хвилини обчислено як 4 * 45.
3Змінні, введення даних і обчислення

Три input з int/float, загальна сума = квиток × учні + автобус, частка з round(…, 2).

Завдання. Калькулятор екскурсії. Програма питає кількість учнів, ціну квитка до музею і вартість автобуса, а потім рахує загальну суму й скільки має здати кожен учень.

Скільки учнів їде? 26
Ціна квитка до музею, грн: 120
Оренда автобуса, грн: 7800
Загальна вартість: 10920 грн
З кожного учня: 420.0 грн

Розв'язок

main.py
students = int(input("Скільки учнів їде? "))
ticket_price = float(input("Ціна квитка до музею, грн: "))
bus_price = float(input("Оренда автобуса, грн: "))
total = ticket_price * students + bus_price
per_student = round(total / students, 2)
print("Загальна вартість:", total, "грн")
print("З кожного учня:", per_student, "грн")
print("Купюр по 100:", int(per_student) // 100, "решта:", int(per_student) % 100)

Як пояснити учням

  1. students = int(input(…)), ticket_price = float(input(…)), bus_price = float(input(…)).
  2. total = ticket_price * students + bus_price — квитки на кожного, автобус один.
  3. per_student = round(total / students, 2) — гривні з копійками.
  4. Вивести обидва числа.
  5. Бонус: купюри по 100 — int(per_student) // 100, решта — % 100.

Де застрягають

  • Забувають int() — тоді input() * 2 повторює текст.
  • Ділять автобус на учнів окремо і плутаються — простіше рахувати загальну суму, потім ділити.
Вимоги «Перевір себе»
  • Три запитання через input().
  • Введені значення перетворено на числа (int або float).
  • Кожне значення зберігається в змінній зі зрозумілою назвою (латиницею, через _).
  • Загальна вартість = квитки × учні + автобус — обчислено в окремій змінній.
  • Сума з кожного учня округлена до копійок: round(…, 2).
  • Бонус: скільки купюр по 100 грн дасть кожен і яку решту — через // і %.
4Рядки та f-рядки

Чотири input, upper/title для імен, f-рядки з вирівнюванням :^30 і рамка "=" * 30.

Завдання. Генератор бейджів для олімпіади. Програма питає ім'я, прізвище, клас і школу, а виводить бейдж: прізвище великими літерами, ім'я з великої, усе по центру рамки.

Ім'я: оля
Прізвище: коваль
Клас: 8-А
Школа: Ліцей «Лідер»
==============================
     ОЛІМПІАДА З ІНФОРМАТИКИ
            КОВАЛЬ
             Оля
             8-А
        Ліцей «Лідер»
==============================

Розв'язок

main.py
first = input("Ім'я: ")
last = input("Прізвище: ")
grade = input("Клас: ")

Як пояснити учням

  1. Записати відповіді у змінні first, last, grade, school.
  2. Рамка: print("=" * 30).
  3. Рядки бейджа: print(f"{last.upper():^30}") — прізвище великими по центру 30 символів.
  4. Ім'я: first.title().
  5. Бонус: ширина w = max(len(school), len(last), 24) + 6 і f"{text:^{w}}".

Де застрягають

  • Забули f перед лапками — фігурні дужки виводяться як текст.
  • Пишуть upper без дужок.
Вимоги «Перевір себе»
  • Чотири запитання через input().
  • Прізвище виведено великими літерами (upper()), ім'я — з великої (title() або capitalize()).
  • Дані на бейджі виведено f-рядками.
  • Рядки бейджа вирівняно по центру (:^).
  • Рамка — повторенням рядка.
  • Бонус: ширина рамки залежить від найдовшого рядка — через len().
5Розгалуження: if, elif, else

float(input) і ланцюжок if / elif / elif / else від найменшої температури.

Завдання. Розумний термостат. Програма питає температуру в класі й виводить стан та пораду: нижче 18 °C — холодно, від 18 до 24 °C — комфортно, від 24 до 28 °C — тепло, вище 28 °C — спекотно.

Температура в класі, °C: 16.5
Холодно. Увімкніть обігрів і зачиніть вікна.

Температура в класі, °C: 26
Тепло. Провітріть клас на перерві.

Розв'язок

main.py
t = float(input("Температура в класі, °C: "))
if t < 18:
    print("Холодно. Увімкніть обігрів і зачиніть вікна.")
elif t <= 24:
    print("Комфортно. Нічого змінювати не треба.")
elif t <= 28:
    print("Тепло. Провітріть клас на перерві.")
else:
    print("Спекотно. Відчиніть вікна й увімкніть кондиціонер.")
h = int(input("Вологість, %: "))
if h < 30:
    print("Сухе повітря — увімкніть зволожувач.")

Як пояснити учням

  1. t = float(input(…)).
  2. if t < 18 → холодно; elif t <= 24 → комфортно; elif t <= 28 → тепло; else → спекотно.
  3. Пояснити: elif перевіряється лише коли попередні умови хибні, тому «t >= 18 and t <= 24» писати не треба.
  4. Бонус: окремий if для вологості < 30 після першого розгалуження.

Де застрягають

  • Один знак = в умові.
  • Неправильний порядок умов (спершу t < 28) — тоді до «холодно» справа не доходить.
Вимоги «Перевір себе»
  • Температуру введено через input() і перетворено на число (float).
  • Розгалуження має чотири гілки: if, два elif і else.
  • Межі 18 і 24 перевіряються правильно (є <= або >=).
  • Кожна гілка виводить стан і пораду.
  • Бонус: друге питання — вологість; якщо вона нижча за 30 %, програма радить увімкнути зволожувач.
6Логічні операції: and, or, not

Відповіді «так/ні» → логічні змінні; головна умова з and, правило згоди з or, причини відмови з not.

Завдання. Допуск до змагань з гонок дронів. Програма питає вік, чи є довідка від лікаря і чи є згода батьків. Учасника допускають, якщо йому від 10 до 17 років, є довідка, а згода батьків є або йому вже 16. Якщо не допущено — програма пояснює причину.

Вік: 15
Довідка від лікаря є? (так/ні): так
Згода батьків є? (так/ні): ні
Не допущено: потрібна згода батьків

Вік: 16
Довідка від лікаря є? (так/ні): так
Згода батьків є? (так/ні): ні
Допущено до змагань!

Розв'язок

main.py
age = int(input("Вік: "))
has_cert = input("Довідка від лікаря є? (так/ні): ").strip().lower() == "так"
has_consent = input("Згода батьків є? (так/ні): ").strip().lower() == "так"
if 10 <= age <= 17 and has_cert and (has_consent or age >= 16):
    print("Допущено до змагань!")
else:
    if not 10 <= age <= 17:
        print("Не допущено: вік має бути від 10 до 17")
    elif not has_cert:
        print("Не допущено: потрібна довідка від лікаря")
    else:
        print("Не допущено: потрібна згода батьків")

Як пояснити учням

  1. age = int(input(…)).
  2. has_cert = input(…).strip().lower() == "так" — у змінній одразу True або False.
  3. Допуск: if 10 <= age <= 17 and has_cert and (has_consent or age >= 16).
  4. У else пояснити причину: if not 10 <= age <= 17 … elif not has_cert … else згода.
  5. Бонус: strip() і lower() приймають «Так » як «так».

Де застрягають

  • Без дужок навколо or умова працює інакше — показати дужки.
  • Пишуть if answer == "так" or "ТАК" — друга частина завжди істинна.
Вимоги «Перевір себе»
  • Три запитання через input(), вік перетворено на int.
  • Відповіді «так/ні» записано в логічні змінні (наприклад has_cert = answer == "так").
  • Умову допуску об'єднано через and.
  • Правило «згода або вік від 16» записано через or.
  • Причину відмови перевірено з not (наприклад if not has_cert:).
  • Бонус: відповіді «Так», « так » теж приймаються — .lower() і .strip().
7Цикл for і функція range

Час переводимо в хвилини, у for рахуємо кінець уроку, виводимо через // 60 і % 60 з :02d.

Завдання. Генератор розкладу дзвінків. Програма питає кількість уроків, тривалість уроку й перерви, а також час початку (години й хвилини окремо) і виводить розклад.

Скільки уроків? 4
Тривалість уроку, хв: 40
Тривалість перерви, хв: 10
Початок — години: 8
Початок — хвилини: 30
1 урок: 08:30–09:10
2 урок: 09:20–10:00
3 урок: 10:10–10:50
4 урок: 11:00–11:40

Розв'язок

main.py
lessons = int(input("Скільки уроків? "))
lesson = int(input("Тривалість уроку, хв: "))
pause = int(input("Тривалість перерви, хв: "))
hour = int(input("Початок — години: "))
minute = int(input("Початок — хвилини: "))
now = hour * 60 + minute
for i in range(1, lessons + 1):
    end = now + lesson
    print(f"{i} урок: {now // 60:02d}:{now % 60:02d}–{end // 60:02d}:{end % 60:02d}")
    now = end
    if i == 3:
        now += 20
    else:
        now += pause

Як пояснити учням

  1. П'ять input: кількість уроків, тривалість, перерва, години, хвилини.
  2. now = hour * 60 + minute — початок у хвилинах.
  3. for i in range(1, lessons + 1): end = now + lesson; print з f"{now // 60:02d}:{now % 60:02d}".
  4. Після уроку now = end + pause (або now += lesson + pause).
  5. Бонус: if i == 3: now += 20, інакше звичайна перерва.

Де застрягають

  • range(lessons) дає номери з 0 — для людей потрібно range(1, lessons + 1).
  • Без :02d виходить 9:5 замість 09:05.
Вимоги «Перевір себе»
  • Усі дані вводяться через input() і перетворюються на числа.
  • Розклад виводить цикл for з range — по рядку на урок, номери з 1.
  • Час перераховано в хвилини й назад через // 60 і % 60.
  • Хвилини виводяться двома цифрами (:02d).
  • Поточний час збільшується в циклі через +=.
  • Бонус: після 3-го уроку велика перерва 20 хвилин (if у циклі).
8Цикл while

while phone > 0: щогодини мінус витрата; коли ≤ 20 і в павербанку ≥ 30 — плюс 30.

Завдання. Модель заряду телефона. Програма питає заряд телефона, скільки відсотків він витрачає за годину і запас павербанка (у відсотках заряду телефона). Щогодини заряд падає; коли він 20 % або менше і в павербанку є запас — підзаряджаємо телефон на 30 %. Програма виводить заряд щогодини і скільки годин протримався телефон.

Заряд телефона, %: 60
Витрата за годину, %: 15
Запас павербанка, %: 30
Година 1: 45 %
Година 2: 30 %
Година 3: 15 % → підзарядка: 45 %
Година 4: 30 %
Година 5: 15 %
Година 6: 0 %
Телефон протримався 6 год

Розв'язок

main.py
phone = int(input("Заряд телефона, %: "))
usage = int(input("Витрата за годину, %: "))
bank = int(input("Запас павербанка, %: "))
hours = 0
while phone > 0:
    hours += 1
    phone -= usage
    if phone < 0:
        phone = 0
    if phone > 0 and phone <= 20 and bank >= 30:
        print(f"Година {hours}: {phone} % → підзарядка: {phone + 30} %")
        phone += 30
        bank -= 30
    else:
        print(f"Година {hours}: {phone} %")
    if hours >= 24:
        print("Вистачить на добу!")
        break
print(f"Телефон протримався {hours} год")

t = turtle.Turtle()

def room(x, y, w, h, name, color="lightgray"):
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.color("black")
    t.fillcolor(color)
    t.begin_fill()
    for i in range(2):

        t.left(90)
        t.forward(h)
        t.left(90)
    t.end_fill()

    t.penup()
    t.goto(x, y)
    t.pendown()
    t.color("green")

    t.setheading(angle)
    t.forward(40)
    t.left(150)
    t.forward(12)
    t.backward(12)
    t.right(300)
    t.forward(12)
    t.pensize(1)

Одна функція caesar(text, shift) з % 33; розшифрування — caesar(t, -k); злам — цикл по ключах 1–32.

Завдання. Шифратор для квесту. Вікно з полем тексту, Spinbox для ключа (1–32) і кнопками «Зашифрувати», «Розшифрувати», «Зламати». Функція <code>caesar(text, shift)</code> повертає зашифрований текст. «Зламати» показує всі 32 варіанти розшифрування.

Текст «Привіт, світ!», ключ 3 → «ТУЙДКХ, ФДКХ!»
«Розшифрувати» з ключем 3 → «ПРИВІТ, СВІТ!»
«Зламати» → 32 рядки «Ключ 1: …», серед них осмислений

Розв'язок

main.py
from tkinter import *

ALPHABET = "АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ"

def caesar(text, shift):
    result = ""
    for ch in text.upper():
        if ch in ALPHABET:
            i = ALPHABET.index(ch)
            result += ALPHABET[(i + shift) % len(ALPHABET)]
        else:
            result += ch
    return result

def encrypt():
    out.config(text=caesar(entry.get(), int(key.get())))

def decrypt():
    out.config(text=caesar(entry.get(), -int(key.get())))

def crack():
    lines = ""
    for k in range(1, 33):
        lines += f"Ключ {k}: {caesar(entry.get(), -k)}\n"
    out.config(text=lines)

def emoji():
    s = ""
    for ch in entry.get():
        s += chr(ord(ch) + 126000)
    out.config(text=s)

window = Tk()
window.title("Шифратор")
entry = Entry(window, width=40)
entry.pack(padx=10, pady=8)
key = Spinbox(window, from_=1, to=32, width=5)
key.pack()
Button(window, text="Зашифрувати", command=encrypt).pack()
Button(window, text="Розшифрувати", command=decrypt).pack()
Button(window, text="Зламати", command=crack).pack()
Button(window, text="Емодзі-шифр", command=emoji).pack()
out = Label(window, text="", justify="left")
out.pack(padx=10, pady=8)
window.mainloop()

Як пояснити учням

  1. def caesar(text, shift): для кожного ch у text.upper(): якщо в ALPHABET — ALPHABET[(i + shift) % len(ALPHABET)], інакше ch без змін; return result.
  2. encrypt: caesar(entry.get(), int(key.get())); decrypt — з мінусом.
  3. crack: for k in range(1, 33): рядок f"Ключ {k}: {caesar(…, -k)}\n".
  4. Вікно: Entry, Spinbox(from_=1, to=32), кнопки, Label для результату.
  5. Бонус: chr(ord(ch) + 126000) — символи стають значками.

Де застрягають

  • Spinbox повертає рядок — потрібен int().
  • Без upper() малі літери не знаходяться в ALPHABET.
Вимоги «Перевір себе»
  • Вікно з полем тексту і Spinbox для ключа.
  • Функція caesar(text, shift) повертає результат через return.
  • Зсув «по колу» через %, розділові знаки й пробіли не змінюються.
  • Кнопки «Зашифрувати» і «Розшифрувати» (розшифрування — зсув -k).
  • «Зламати» перебирає ключі 1–32 циклом.
  • Бонус: «Емодзі-шифр» через ord і chr.
14Віконні програми: розмітка grid і перевірка введення

grid-форма, допоміжні num(e) і put(e, x), три функції з try/except ValueError і ZeroDivisionError.

Завдання. Калькулятор закону Ома. Три підписані поля (напруга, струм, опір) на grid і три кнопки: «Знайти U», «Знайти I», «Знайти R». Кнопка рахує величину з двох інших і записує результат у її поле. Неправильне введення й ділення на нуль — зрозуміле повідомлення в написі.

def num(e):
    return float(e.get())

    e.delete(0, "end")
    e.insert(0, str(round(x, 3)))

    try:
        put(u, num(i) * num(r))
        msg.config(text="")

Завдання. Власна гра на Pygame Zero. Спроєктуй і створи гру, де гравець ловить або обминає об'єкти.

Кілька об'єктів падають одночасно
Зліва вгорі: Рахунок 12   Життя: 2
Життя закінчились → «Гру закінчено. Пробіл — заново»

Розв'язок

game.py
# Урок 16. Гра «Порося ловить жолуді»
# Ідея: аркада-ловилка; мета — зловити якомога більше жолудів; керування ← →
# Запуск: Thonny / VS Code з бібліотекою pgzero.
# Поруч з файлом — папка images/ з pig.png і acorn.png.
import pgzrun
import random

WIDTH = 800
HEIGHT = 600
TITLE = "Порося і жолуді"

player = Actor("pig")
player.pos = (400, 540)
acorns = []            # список падаючих об'єктів
score = 0
lives = 3
speed = 3              # швидкість падіння — зростає з часом
game_over = False


def new_acorn():
    acorn = Actor("acorn")
    acorn.pos = (random.randint(20, WIDTH - 20), random.randint(-300, -20))
    acorns.append(acorn)


def reset():
    global score, lives, speed, game_over
    score = 0
    lives = 3
    speed = 3
    game_over = False
    acorns.clear()
    player.pos = (400, 540)
    for i in range(3):              # одночасно кілька жолудів
        new_acorn()


def draw():
    screen.fill((20, 24, 48))
    if game_over:
        screen.draw.text("Гру закінчено. Пробіл — заново", center=(400, 280),
                         fontsize=48, color="white")
        screen.draw.text(f"Рахунок: {score}", center=(400, 340),
                         fontsize=36, color="gold")
        return
    player.draw()
    for acorn in acorns:
        acorn.draw()
    screen.draw.text(f"Рахунок {score}   Життя: {lives}", topleft=(10, 10),
                     fontsize=32, color="white")


def update():
    global score, lives, speed, game_over
    if game_over:
        return
    # керування гравцем
    if keyboard.left and player.left > 0:
        player.x -= 6
    if keyboard.right and player.right < WIDTH:
        player.x += 6

    for acorn in acorns[:]:         # [:] — копія, бо список змінюємо в циклі
        acorn.y += speed
        if player.colliderect(acorn):
            score += 1
            acorns.remove(acorn)
            new_acorn()
            if score % 5 == 0:      # ускладнення: кожні 5 очок
                speed += 0.5
                new_acorn()         # і ще один жолудь
        elif acorn.top > HEIGHT:
            lives -= 1
            acorns.remove(acorn)
            new_acorn()
            if lives == 0:
                game_over = True


def on_key_down(key):
    if game_over and key == keys.SPACE:   # перезапуск пробілом
        reset()


reset()
pgzrun.go()

Як пояснити учням

  1. Спершу коментар з ідеєю гри: жанр, мета, керування.
  2. acorns = [] і функція new_acorn() з випадковою позицією вгорі; reset() створює 3 об'єкти.
  3. update: керування keyboard.left/right; для кожного об'єкта y += speed, colliderect → очко, вилетів — мінус життя.
  4. draw: фон, гравець, об'єкти, screen.draw.text з рахунком; якщо game_over — екран «Гру закінчено».
  5. on_key_down: пробіл при game_over → reset(). Ускладнення: кожні 5 очок speed += 0.5.

Де застрягають

  • Запуск у браузері — пояснити, що потрібні Thonny/VS Code і pgzero.
  • Немає папки images або назва з великої літери.
Вимоги «Перевір себе»
  • Спершу запиши ідею гри: жанр, мета, керування (коментарем угорі коду).
  • Керування гравцем з клавіатури.
